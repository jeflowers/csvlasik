# Scheduler Quick Reference Guide

## 🚀 Quick Start

**Access Dashboard:** `/admin/appointments`

**Your Role:** Scheduler - You can view and manage consultation requests

---

## 📋 Dashboard Overview

### Filter Bar
- **All** - See all requests
- **Unassigned** - New requests waiting for assignment
- **Mine** - Requests assigned to you
- **Assigned** - All assigned requests
- **Scheduled** - Confirmed appointments
- **Closed** - Completed requests

### Search Box
Type to search by:
- Patient name (first or last)
- Email address
- Phone number

---

## 🎯 Request Status

| Status | Meaning | Action Needed |
|--------|---------|---------------|
| 🟡 UNASSIGNED | Just received | Assign to yourself or teammate |
| 🔵 ASSIGNED | Someone is handling it | Contact patient if yours |
| 🟢 SCHEDULED | Appointment confirmed | Follow up if needed |
| ⚫ CLOSED | Request completed | No action needed |

---

## 🛠️ Actions Available

### Built-in Scheduler Mode

**📞 Contact**
- Click to open contact modal
- Call or email the patient
- Document the conversation

**✅ Mark as Scheduled**
- Click when appointment is confirmed
- Moves request to "Scheduled" status

**📝 Add Note**
- Document call outcomes
- Add follow-up reminders
- Note any special requests

**👤 Assign**
- Assign request to yourself
- Or delegate to a teammate

---

### RingCentral Mode

**📞 Open RC Booking**
- Opens RingCentral with patient info pre-filled
- Schedule in RC calendar
- System auto-syncs back

**☎️ Click-to-Call**
- Initiates phone call via RingCentral
- Patient number dialed automatically

**💬 Send RC SMS**
- Opens SMS composer
- Patient number pre-filled
- Send confirmation or follow-up

---

### Hybrid Mode

**Schedule Dropdown**
- Choose: Built-in Scheduler
- Or: RingCentral Booking
- Use whichever fits the situation

---

## ⏱️ Typical Workflow

### Morning Routine (5 minutes)
1. Open Dashboard
2. Click "Unassigned" filter
3. Review new overnight requests
4. Assign urgent ones to yourself

### Throughout Day (2 min per request)
1. Click "Mine" filter
2. Contact each patient
3. Schedule appointment
4. Mark as "Scheduled"
5. Add note with details

### End of Day (5 minutes)
1. Review any still unassigned
2. Assign or close old requests
3. Add notes for tomorrow

## 💡 Pro Tips

### Efficiency Tips
- Use search instead of scrolling
- Keep "Mine" filter open in a tab
- Add notes immediately after calls
- Batch similar tasks (all calls, then all emails)

### Best Practices
- Respond to requests within 2 hours
- Always add a note after contact
- Mark as scheduled only when confirmed
- Close requests that are cancelled

### Common Situations

**Patient doesn't answer:**
- Add note: "Called, no answer. Left voicemail."
- Try email next
- Follow up in 24 hours

**Patient requests specific time:**
- Check availability first
- Confirm via their preferred method
- Add note with appointment details

**Patient wants to cancel:**
- Mark as "Closed"
- Add note: "Patient cancelled - [reason]"
- No further action needed

**Duplicate request:**
- System usually catches these
- If you spot one, close newer request
- Add note: "Duplicate of [Request ID]"

## 🚨 When to Escalate

Contact your supervisor if:
- Patient has medical emergency → Call 911 first
- Patient is hostile or threatening → Document and escalate
- Technical issue prevents scheduling → IT support
- RingCentral is down → Use built-in scheduler

## ❓ FAQs

**Q: Can I assign a request to multiple schedulers?**
A: No, one request = one scheduler. If multiple people need to be involved, use notes to coordinate.

**Q: What if I accidentally mark something as scheduled?**
A: Click the request, change status back, and add a note explaining the correction.

**Q: How long should I keep trying to reach a patient?**
A: 3 attempts over 3 days (call, email, SMS). If no response, add note and close.

**Q: Can I edit patient information?**
A: No, that's admin-only. If patient info is wrong, add a note and ask admin to update.

**Q: What does "All actions logged for compliance" mean?**
A: Every click, note, and status change is recorded for HIPAA compliance. Always document accurately.

**Q: Why can't I see some requests?**
A: You can only see requests for your practice/location. Check with admin if you think something's missing.
